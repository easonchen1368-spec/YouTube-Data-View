# YouTuber 資料快速查看器
YouTuber 資料快速查看器 是一款輕量、直覺的 Chrome 擴充功能。瀏覽 YouTube 時，右下角會常駐專屬懸浮按鈕，滑鼠輕輕移入即可自動展開頻道資訊面板，即時查看訂閱人數、公開影片數、累計觀看次數及最新影片。擴充功能內建預設 API，同時支援使用者自訂金鑰，讓數據查詢流暢不中斷！

# 下載教學
📖 安裝與使用教學
下載專案：點擊綠色「Code」按鈕選擇「Download ZIP」並解壓縮。
載入擴充：開啟 Chrome 瀏覽器，網址列輸入 chrome://extensions/，開啟右上角「開發人員模式」，點擊「載入未封裝項目」並選擇解壓縮後的資料夾。
即時體驗：進入任意 YouTube 頻道或影片頁面，滑鼠移至右下角懸浮按鈕即可自動查看完整數據！
